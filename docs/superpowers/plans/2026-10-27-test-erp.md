# Test ERP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic FastAPI test ERP on `127.0.0.1:8081` that fully implements the REST contracts behind all 23 MCP tools.

**Architecture:** `TestERPStore` owns thread-safe, mutable in-memory state copied from immutable seed data. Four thin FastAPI routers validate HTTP input and delegate to the store, returning a common `{code, message, data}` response envelope. Tests cover HTTP contracts first, then invoke registered MCP tools against a real in-process test server.

**Tech Stack:** Python 3.11+, FastAPI, Pydantic v2, Uvicorn, httpx, unittest, FastMCP.

**Spec:** `docs/superpowers/specs/2026-10-27-test-erp-design.md`

## Global Constraints

- The service binds only to `127.0.0.1` and defaults to port `8081`.
- State exists only in process memory and resets from immutable seed data at startup.
- Implement exactly the 23 REST contracts consumed by `src/mcp_server/tools/`; do not modify those production modules.
- Successful calls return the documented `code/message/data` envelope; use 400, 404, and 409 envelopes for validation, missing resources, and stock conflicts.
- Do not read, edit, or depend on the project's `.env`; MCP selection remains an explicit launch-time `ERP_BASE_URL` setting.
- Preserve unrelated working-tree changes to `README.md` and `.env.example`.

class TestERPStore:
    def create_order(self, payload: dict) -> dict:
        details = self._validated_order_details(payload.get("orderDetail"))
        order = {**payload, "id": self._next_id("order"), "orderDetail": details}
        order["totalAmount"] = payload.get("totalAmount") or sum(

        )
        self._orders.append(order)
        return copy.deepcopy(order)
